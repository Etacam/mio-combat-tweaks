# Combat Tweaks

Fixes some issues with Mio's combat system and allows you to customise the damage of slashes.

## Features

All these features are off by default and must be enabled in the mod settings menu

* You can customise the damage of certain attacks:
    * Slashes
    * Sharpened Hairpin
    * Sharpened Hairpin crit multiplier
    * Strider spear
* Display damage numbers
* Fix Wildcat being cancelled by other sources of damage such as Glitch Trail, Firefly and Slingshot targets
* Fix strider spear doing less damage than intended at max damage upgrades
